# Instagram Content Strategy — Hexa AI Agency

## The Goal
Turn Instagram Reels into a client acquisition machine. Every reel should either grow reach OR generate leads. No vanity content.

---

## Hook Formulas (First 3 Seconds = Everything)

The algorithm tests your reel on 200-500 people first. If they scroll past in the first 3 seconds, the reel dies. Use these proven formulas:

### 1. Stat Shock (Best for reach)
"[Surprising number]. [Relatable pain]. [Promise of fix]."
- "Dental practices lose $150K per year to no-shows. Here's the fix nobody talks about."
- "The average property manager spends 23 hours a week on tenant messages. That's insane."
- "68% of cleaning contracts are lost because of ONE communication failure."

### 2. Contrarian / "Stop Doing X" (2-3x better than educational hooks)
- "Stop sending appointment reminder texts. They don't work."
- "Every property manager is doing tenant communication wrong."
- "If you're still scheduling cleaning crews manually, you're bleeding money."

### 3. Curiosity Gap (Highest watch-through rate)
"[Tease a result] + [withhold the method]"
- "We automated ONE process for a dental office. Revenue jumped 30% in 60 days."
- "This 4-minute setup saved a cleaning company 15 hours per week."
- "A property manager DM'd me this screenshot. I couldn't believe the numbers."

### 4. Direct Question (Highest conversion, lower reach)
- "How many appointments did your dental practice lose this month?"
- "What if tenants could resolve 80% of issues without calling you?"

### Pro Tip: Combine TWO hook types
Stat Shock + Curiosity Gap = "Dental no-shows cost practices $150K/year. We fixed it with one automation — here's what happened."

## Content Structure Templates

### Template A: Problem-Agitation-Solution (PAS) — 30s
Best for: Lead generation, driving DMs
```
0-3s:   Hook (stat shock or contrarian)
3-10s:  Agitate — what it FEELS like to deal with this daily
10-25s: Solution — show the automation/system (walkthrough, before-after)
25-30s: CTA — "Comment [KEYWORD] for the full breakdown"
```

### Template B: Before/After — 30s
Best for: Social proof, shares
```
0-3s:   "Here's what [business] looked like BEFORE automation"
3-12s:  Show the messy manual process (real, relatable)
12-15s: Transition — "And here's what it looks like NOW"
15-25s: Show the clean automated flow
25-30s: CTA
```

### Template C: 3 Mistakes Listicle — 30s
Best for: Saves, algorithm distribution
```
0-3s:   "3 reasons your [business] is losing [money/clients/time]"
3-8s:   Mistake 1 (quick, text overlay)
8-14s:  Mistake 2
14-20s: Mistake 3
20-25s: Quick fix overview
25-30s: CTA
```

### Template D: Case Study / Client Result — 45-60s
Best for: Bottom-of-funnel, trust building
```
0-3s:   "We just saved a [business] [specific result]"
3-15s:  What was happening before (the pain)
15-40s: What we built and the result (metrics, screenshots)
40-50s: Client quote or testimonial
50-60s: CTA
```

## CTA Strategy (Comment-to-DM Funnel)

Every reel MUST have a keyword CTA. This is the lead engine.

### Keywords by Niche
| Niche | Keyword | Lead Magnet |
|-------|---------|-------------|
| Dental | DENTAL | No-show cost calculator + automation playbook |
| Property Mgmt | PROPERTY | Tenant communication automation checklist |
| Cleaning | CLEAN | Scheduling efficiency audit template |
| General | AUTOMATE | AI automation ROI calculator |

### CTA Rules
1. **Say the keyword 2-3 times.** "Comment DENTAL. That's D-E-N-T-A-L. And I'll DM you the playbook."
2. **Show a text overlay CTA at 3-5 seconds AND at the end.** Most viewers don't finish.
3. **Never just say "link in bio."** Comment keywords drive 5-10x more leads because each comment boosts the algorithm.
4. **Add a "send this to" CTA for shares.** "Send this to a dentist who's still doing reminder calls manually." Shares are the #1 algorithm signal.

### ManyChat DM Sequence (Phase 2)
```
Comment detected → Wait 60-120s → DM lead magnet
→ Ask qualifying question ("What type of business?")
→ Personalize response based on niche
→ Offer free audit/call → Send Calendly link
→ Follow up Day 2, Day 4, Day 7 if no booking
```

## Algorithm Optimization

### What Boosts Distribution
1. **Completion rate** — Keep reels 15-30s for hooks, 45-60s for deep content. Avoid 30-45s dead zone.
2. **Shares (DM sends)** — Add "send this to a [role]" CTAs
3. **Saves** — Educational listicles get saved most
4. **Comments** — Comment-to-DM keywords drive volume
5. **Consistency** — 5-7 reels/week, never drop below 3

### What Kills Distribution
- Boring first 3 seconds (low completion rate)
- Posting fewer than 3x/week after being consistent
- External links in caption (reduced reach)
- Cross-posted content with TikTok watermarks
- Generic mega-hashtags (#entrepreneur, #business)

### Hashtag Strategy (3-5 per reel)
Use niche-specific tags only:
- Dental: #dentalautomation #dentalpractice #dentalmarketing #dentistlife
- Property: #propertymanagement #landlordtips #propertytechnology #rentalproperty
- Cleaning: #cleaningbusiness #cleaningcompany #janitorial #commercialcleaning
- General: #aiautomation #businessautomation #smallbusinesstips #workflowautomation

### Posting Schedule
Best times for B2B service businesses:
- **Morning:** 6-8am (before their workday starts)
- **Lunch:** 12-1pm (break scrolling)
- **Evening:** 7-9pm (wind-down scrolling)
- **Best days:** Tuesday-Thursday
- **Avoid:** Weekends (lower B2B engagement)

## Reel Length Guidelines

Match length to content depth:
- **15-30s:** Quick hooks, stat shocks, single tips, CTAs
- **45-60s:** PAS sequences, case studies, tutorials
- **60-90s:** Detailed walkthroughs, build-with-me content
- **Never:** 30-45s (dead zone — too long for quick, too short for substance)
